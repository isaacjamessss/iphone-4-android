Found / done:

  parses Apple DT): iPhone 4 touch = SPI1, reset GPIO 0x204, CS 0x601, irq 0x15,

  T4 driver never enables an LDO -> controller unpowered -> SPI reads ffffffff.

  Read 0x16=0x6c (LDO12 off) before. touch/t4-touch-start.sh does it at boot.

  movw r2,#0x6e31 -> #0x4e31 at file 0x8fac.
- Per-unit calibration: `idevicediagnostics ioreg IODeviceTree multi-touch` from
  STOCK iOS 6.1.3 (no SSH needed) -> multi-touch-calibration 256 B ->
  touch/mtcal-n92.bin (contains a serial: keep out of public repo). Embedded at
  driver file offset 0x19d90 (n81_device_cal, 1024 B slot, rest zeros = same as iPod).
  -> ghost touches at boot gone, cal upload ACKed.
- SPI speed is NOT the problem: A4 SPI is spi-apple layout (CLKDIV=0x30,
  WORD_DELAY=0x38, NOT openiboot's 0x18). xfer() takes clkdiv as arg; frames use 3,
  firmware 5. div 5 for frames broke header reads (t4-touch-input-n92d5, dropped).
- Raw capture (touch/memdump = ptrace /proc/pid/mem dumper; snapshots in
  touch/capture/stk*.bin, frames at stack offset 0x2081c): ALL captured frames have
  VALID checksums (sum of bytes [5 .. L+3) == u16 at [L+3]). Frames: `ea 0? 38 00 dc 44 ..`
  (L=56, single finger?) and one L=146 (multi-finger).
- Stage-5 errors were header-announced length (0x56) != frame length (0x38).
  t4-touch-input-n92len (patch 0x99e4 mov r10,r3 / 0x99e8 add r5,r7,#3) trusts the
